# Servetus Time Rules (MVP)

## Timezone
All timestamps default to:
- `America/Chicago`

## Default Timestamp Policy
- If exporting and no time is specified, use **NOW**.
- Prefer ISO-8601 with timezone offset when available.
- Do not fabricate seconds; minute precision is sufficient.

## When to Use `unknown`
Use `unknown` only when:
- the content clearly refers to a past event, AND
- no timestamp exists in the thread, AND
- you cannot safely infer it.

If `unknown` is used:
- add a note in `## Links / References` explaining what is missing.
