# Overrides (MVP)

## Purpose
Project-specific switches that customize behavior without editing authority files.

```yaml
overrides:
  export:
    topic_segmentation: true
    insert_new_topic_headers_live: true
    suggest_tags_on_topic_switch: true
    ask_sort_question_on_topic_switch: true
    max_suggested_tags: 5

  output:
    be_chatty_outside_export: true
    be_zero_fluff_in_export: true

  safety:
    redact_secrets: true

  spelling:
    enforce_SEVEN_TALENTS: true
