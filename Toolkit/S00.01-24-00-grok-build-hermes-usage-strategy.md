## Plain English Goal
Stop the fragmentation and "figuring out" tax. Have a crisp, documented, launcher-supported model so that:
- Hermes is the reliable daily runtime harness (skills, dispatch, voice, persistent agents, home automation, the "shell").
- Grok Build is the high-power contractor tool used *outside* the harness for design spikes, parallel exploration (subagents + worktrees), precise multi-file work, GitHub/PRs, authoring the specs that then load into Hermes.
- The tmux control room (servitus) is the "everything" meta-view when you want all engines visible at once (video-mixer/ATEM model, user as TD).
- Capture, git, and vault sovereignty are non-negotiable for every path.
- Launching the right thing for the job is one or two commands (servetus, servetus-h, servetus-g, etc.).

## Division of Labor (proposed)
- **Hermes Harness (runtime)**: The persistent, skill-driven, dispatch-oriented, voice-first operating environment. Use for: daily tasks, agent orchestration, long-running monitors (transcription queue, live transcript, bot), voice conversations, home automation, anything that benefits from the boot skill + vault context + skill catalog. Launch via servetus (full room) or servetus-h (quick single).
- **Grok Build (contractor)**: High-leverage, stateless-per-session, planning + execution engine. Use for: designing new systems (this work), complex refactors, parallel investigation (multiple subagents), authoring specs that become Hermes skills, GitHub work (branches, PRs, reviews), anything requiring worktrees or heavy editing. Launch via servetus-g. "Outside the harness" by design for the building phase.
- **Tmux Control Room (meta)**: When you want simultaneous visibility and orchestration across engines (user as TD calling shots via Control pane). The "hantainer". servetus launches it.
- **Other engines** (Claude Code direct, Ollama): Via -c / -o for specific precision or bulk needs.

Handoff: Grok Build session ends with committed changes to vault (specs, code, docs). Hermes next launch (or skill reload) picks them up. Raw transcripts/artifacts always captured back to vault first.
