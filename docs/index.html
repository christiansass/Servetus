The problem with AI memory

Modern AI tools store your life in opaque databases, process it through black-box models, and return interpretations you cannot verify.

When the AI says "you discussed X with Y on Z date" — how do you know that's true?

You don't. You trust the model. And models hallucinate.

Servetus solves this with a simple principle: every claim traces back to an artifact. The artifact is the evidence. The AI is the interpreter. You are the authority.

The artifact chain

Reality — what actually happened
↓
Artifacts — photos, audio, transcripts, screenshots. The tape.
↓
Memories — atomized thoughts extracted from artifacts
↓
Events / Projects / Arcs — structured, organized, linked
↓
AI Processing — interpretation, assistance, synthesis
↓
Human Review — you correct what's wrong
↓
Reality Check — you can always go back to the artifact

The AI sits in the middle of the stack, not at the top. It serves the system. It does not rule it.

The session bracket

Every Claude Code session is a bracketed work unit — opened with context, closed with a full-fidelity artifact. Nothing is lost.

$ sc # open bracketed session
 
┌─────────────────────────────────────────────────┐
│ SESSION 12% filled · 47 turns · active 2h 14m │
│ LAST 3h 22m ago · today 04:41 · Servetus Dev │
│ MEMORY CLAUDE.md 12kb · 8 specs loaded │
│ ARCS binary-ranch · seven-talents · the-inklings │
│ SYSTEM session-close ✓ statusline ✓ git clean │
└─────────────────────────────────────────────────┘
 
# ... work happens ...
 
$ session-close
[session-close] Artifact: Inbox/Claude/2026-03-18-claude-session-604ab0e7/
[session-close] Turns: 67 user / 80 assistant
[session-close] Brief: 10-System/last-session-brief.md
[session-close] Registry: session marked closed

The JSONL is the tape. The Markdown artifact is the record. The brief is the memory. All three are plain files — no database, no API, no black box.

What's shipped in v0.3.0

◈

KITT Statusline

Running clock ticking every second. Session age. Room label. Red bouncing scanner on AI thinking.

▤

Launch Brief

Session-opening intelligence dashboard — last session, open threads, memory load, radar, arc status.

⇄

Hopper Pipeline

Background file watcher + triage + two-stage filer. New files announced to terminal without touching the LLM.

◉

Full-Fidelity Artifacts

Every session: JSONL raw witness + rich Markdown transcript + extracted images, co-located in one folder.

⚠

Orphan Scanner

Detects real sessions closed without artifacts. Surfaces them in the launch brief at next open.

⌚

Timecode, Not Timestamps

Per-turn timestamps with millisecond precision. Local time always. Seconds pattern distinguishes human vs automated.

Install

Clone into your Obsidian vault location, then run the installer for your platform.

macOS / Linux
bash install.sh
Windows (PowerShell)
./install.ps1

Then type sc to open a bracketed session. Read Toolkit/bootloader.md to understand the system.

The name

Michael Servetus (1511–1553) was burned at the stake in Geneva. His crime: reading the biblical text and arriving at conclusions that contradicted the institutional interpretation.

When it's one man's word against another, whoever controls the interpretation layer wins.

Servetus (the system) ensures the interpretation layer is never controlled by a single authority — AI, institution, or otherwise. Artifacts are the check. Corroboration is the standard.

A servant, not a master. A witness, not an authority.
