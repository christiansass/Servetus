If you're technically minded, here's exactly what's happening — and what isn't.

This page is a static HTML file hosted on GitHub Pages. It has no backend, no server, no database, no tracking, no analytics, no cookies, no form submissions. You can read every line of source right now.

The generator never asks for your credentials. What it produces is a self-contained JavaScript bookmarklet — a javascript: URL you drag to your bookmarks bar. That bookmarklet contains no username, no password, no Nextcloud URL. On first click, it prompts you for those three things directly in your browser. They are written to your browser's localStorage — a sandboxed, device-local key-value store that no external party can read or access. They never leave your machine.

Use a Nextcloud app password, not your account password. Generate one at Nextcloud → Settings → Security → App passwords. Scope it. Name it. If it's ever compromised, revoke that one token — your account and all other sessions remain unaffected.

The write path is direct: your browser sends a PUT request via WebDAV straight to your Nextcloud instance. No relay, no proxy, no middleman service ever sees the request or the content. The generated note goes from your clipboard to your server in one hop.

To reset or revoke: run localStorage.clear() in your browser console, or revoke the app password in Nextcloud. The bookmarklet will prompt fresh on next use.
