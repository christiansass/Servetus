# macOS Clipboard History — Utilities and Methods

**Source:** 2025-07-17-Clipboard_History_on_Mac.md
**Date:** 2025-07-17

## Summary

Query on accessing clipboard history on macOS. Native macOS has no clipboard history — only current item. Third-party tools required.

## Native macOS (No History)

- `pbpaste` / `pbcopy` in Terminal — access/set current clipboard only
- Universal Clipboard (Apple ecosystem) — cross-device, but still only latest item

## Third-Party Clipboard History Tools

| App | Notes |
|-----|-------|
| **Paste** (pasteapp.io) | Full history; sync; iCloud; popular |
| **Clipboard Manager** (various) | Several free options in App Store |
| **Alfred** | Clipboard history as a feature within broader launcher |
| **Raycast** | Free; built-in clipboard history |
| **Maccy** | Open-source, lightweight, free |

## Recommended

For lightweight free solution: **Maccy** or **Raycast**. For full-featured with iCloud sync: **Paste**.
