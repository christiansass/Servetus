# Cryptocurrency Network Background — Layered SVG Design

**Source:** 2026-01-21-Cryptocurrency_Background_Vector_Request.md
**Date:** 2026-01-21

## Summary

Design session for a background vector graphic representing cryptocurrency, Bitcoin, banking institutions, and financial nodes. Resulted in a layered SVG (1024×1024) with independent icon elements, shield prominently centered, scaled radially (larger in center, smaller toward edges for spherical composition effect).

## Design Spec

- **Style**: thick-pen monoline, flat material design, no shading
- **Icons**: shield (center, prominent), Bitcoin, bank building, wallet, coins, globe, chart, phone, nodes
- **Layout**: organic placement overall, but each icon geometrically symmetrical and clean
- **Composition**: spherical scaling — largest elements center, progressively smaller toward edges
- **SVG structure**: `<symbol>` definitions for each icon, `<use>` elements as independent layers; network lines on separate layer
- **Use case**: background pattern/tile for financial/crypto content

## Technical Notes

- Layered SVG produced with `<defs>` + `<symbol>` + `<use>` architecture — each icon editable/movable independently
- Suitable for Figma, Illustrator, Inkscape
