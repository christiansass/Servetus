# ChatGPT Voice Mode Bug — macOS Desktop App Workaround

**Source:** 2025-12-20-Clarify_speaking_target.md
**Date:** 2025-12-20

## Summary

Voice mode in the ChatGPT macOS native app was not working (cutting out, unavailable, or unstable). Session identified the bug and workaround.

## Problem

- ChatGPT macOS native app had voice mode broken/unstable at this time
- A bug introduced in a recent update caused voice output to start and cut itself off repeatedly

## Workaround

Voice mode still fully available via:
1. **Browser at chatgpt.com** — generally more stable than Mac app
2. **iOS/Android mobile apps** — normally easiest way to access voice mode

## Note

This was a known bug as of Dec 2025; likely fixed in subsequent app updates.
