# Verbal Processor — Building External Memory

## The Condition

Christian Sass identifies as a **verbal processor** — someone who thinks by speaking aloud.
Memory recall is emotional and visual, not textual or verbal reconstruction.

- Cannot reconstruct conversations or events verbally on demand
- Loses information within hours if not externalized
- Has carried a Franklin planner since junior high — externalizing memory is not new, just scaling
- Contrast: wife remembers a phone number after dialing once; he struggles with a 4-digit PIN

> *"I'm writing for my own handicap of my inability to recall things in the right time."*

## The Goal

**Perfect recall through externalizing.** Not for productivity — for basic functioning.

Building a core context and memory system for private LLM use within his own life:
- 10x or 100x capabilities by not losing what was brilliant in the moment
- The question the wife asks — "what did you do today?" — becomes answerable
- The system creates the record so the person doesn't have to hold it

## Why Servetus Is Personal Infrastructure

This isn't a product first. It's a personal prosthetic built for a specific cognitive style:
- Think out loud → record → transcribe → atomize → store → retrieve
- The LLM is not the intelligence. It's the retrieval and synthesis layer on top of the record.

> *"I'm building a core context and memory system for private, large language model use within my own life."*

## The Workflow (as described)

1. Brain dump via voice recording — offline, in the truck, on the bus, anywhere
2. Device gains network access
3. Audio → LLM → text → atoms → stored in Servetus
4. Information becomes retrievable on demand
