# Mac Mini M4 Pro — Creator/Cinema Workstation Design

**Source:** 2025-11-26-Ultimate_Mac_workstation_setup.md
**Date:** 2025-11-26

## Summary

Designing a dual-purpose creator-by-day / cinema-by-night Mac workstation using a 4K display that doubles as a film viewing setup with 5.1 surround. macOS ecosystem required.

## Core Tension

- macOS looks best at ~110–220 PPI with HiDPI scaling (Apple ships 5K/6K displays)
- Cinema: 4K OLED + good HDR + proper surround
- Goal: find 4K screen size that macOS can scale cleanly AND feels like a legit TV at night

## Recommended Mac Brain

**Mac mini (M4 Pro)** — top recommendation for value
- HDMI 2.1 + Thunderbolt 5 for 4K high-refresh + eARC audio routing
- Supports Dolby Atmos / multichannel playback in macOS
- Whisper quiet; tiny footprint
- Suggested spec: M4 Pro, 48–64GB unified memory
