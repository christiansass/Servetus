# Servetus Dev Backlog

System development tasks, architecture decisions, and feature work.
Each file is one item. Frontmatter carries status and priority.

**Rule:** If it's about improving Servetus → here.
If it's about life, business, ministry, relationships → `06-Radar/open-loops.md`.

Open-loops.md may carry a pointer to a file here, but detail lives here.

## Status values
- `open` — not started
- `in-progress` — actively being worked
- `blocked` — waiting on something
- `done` — complete
